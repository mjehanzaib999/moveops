# MoveOps — AI use cases

The AI features inside MoveOps, each powered by Claude (`anthropic/claude-sonnet-4.5`) via OpenRouter and each degrading to a deterministic fallback when no API key is configured. Every use case has a full breakdown below.

### AI Move Estimator
Turns a free-text move description into a professional volumetric survey — room-by-room inventory, total volume, crew/truck/hours and a price range — with Claude streaming its reasoning first.

[Read the full breakdown →](./ai-move-estimator.md)

### Lead Intelligence
Scores every open lead by conversion likelihood from real pipeline signals and hands the rep the single best next action, sorted hottest-first.

[Read the full breakdown →](./lead-intelligence.md)

### Instant AI Quote
Lets public visitors describe a move in plain English and get an instant price range, with the AI reading intent and a rules engine setting the number.

[Read the full breakdown →](./instant-ai-quote.md)

### Booking Chatbot
An embeddable, tool-calling assistant that answers grounded FAQs, quotes, and captures consent-gated leads straight into the CRM.

[Read the full breakdown →](./booking-chatbot.md)
